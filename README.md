# Marquee Socials

**Manage all your social media accounts in one place.**

A sleek desktop app for creators who need to manage multiple social media platforms efficiently.

## Features

- **Unified Dashboard** — See all your platforms at a glance
- **Tabbed Browsing** — Open multiple platforms in tabs, switch instantly
- **One-Click Access** — Jump to any platform with a single click
- **Shared Login Sessions** — Stay logged in across all platforms
- **Purple-themed UI** — Clean, modern interface

## Supported Platforms

- YouTube Studio
- TikTok Studio
- Instagram
- X (Twitter)
- Discord
- Telegram

## Installation

### From Omarchy Store (Recommended)
One-click install from [omarchystore.com/app/marquee-socials](https://omarchystore.com/app/marquee-socials)

### Manual Installation
```bash
git clone https://github.com/omarchy-development-labs/marquee-socials.git
cd marquee-socials
chmod +x run.sh
./run.sh
```

## Usage

1. Launch Marquee Socials from your app launcher
2. Click any platform card to open it in a new tab
3. Use the sidebar for quick navigation
4. Click "Open All" to open all platforms at once

## Privacy

Marquee Socials uses your local browser profile — all logins and sessions are stored locally on your machine. We never collect or transmit your social media credentials.
